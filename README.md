## 🔒 보안 및 접속 안내
- **접속 비밀번호**: `나는농협입니다`
- **한/영 자동 인식**: 한글 자판(`나는농협입니다`), 영타 오타(`sksmsshdguqdlqslek`), 띄어쓰기 유무와 무관하게 100% 자동 통과

## 🛡️ 안정성 최적화 (Zero-Crash Engine)
- **재귀적 `setTimeout`**: 스택 오버플로 및 메모리 누수 원천 차단
- **요청 폼 캐싱**: 매 회차 메모리 할당 99% 절감
- **코레일 10분 세션 만료 킬러 방지 (`keepAlive`)**: 가상 사용자 활동 디스패치로 장시간 무중단 유지
- **4초 타임아웃 안전망 (`AbortController`)**: 소켓 점유 방지
