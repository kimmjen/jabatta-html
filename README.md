# 🚄 잡았다 (Jabatta) 북마클릿 웹 생성기

별도 프로그램 설치 없이 웹 브라우저에서 1초 만에 등록하는 초경량 코레일(KTX/SRT) 취소표 자동 예약 도우미 웹서비스입니다.

🔗 **공식 웹사이트**: [https://kimmjen.github.io/jabatta-html/](https://kimmjen.github.io/jabatta-html/)

---

## 🔒 1. 보안 및 접속 안내
- **접속 비밀번호**: `나는농협입니다`
- **한/영 자동 인식**: 두벌식 자판 자동 변환 엔진이 내장되어 있어, 한글 자판(`나는농협입니다`), 영타 오타(`sksmsshdguqdlqslek`), 띄어쓰기 유무와 무관하게 100% 자동 통과됩니다.
- **개인정보 완벽 보호**: 텔레그램 토큰, 채팅 ID, 열차 설정값은 서버로 절대 전송되지 않으며 사용자의 로컬 브라우저(`localStorage`)에만 안전하게 자동 저장(Auto-save)됩니다.

## 🛡️ 4. 안정성 아키텍처 (Zero-Crash Engine)
장시간 매크로 실행 시 발생하는 브라우저 프로세스 충돌(Crash, SIGTRAP, Aw Snap!)을 완벽히 방지하는 5대 보호 시스템이 탑재되어 있습니다.

1. **재귀적 `setTimeout` 방식**: `setInterval`의 타이머 큐 누적과 콜 스택 오버플로를 원천 차단하여 메모리 누수 0% 유지
2. **요청 폼 데이터 사전 캐싱**: 매 틱마다 생성되던 대형 객체를 시작 시 1회만 생성하여 메모리 할당 99% 절감
3. **`cache: 'no-store'` 네트워크 캐시 방지**: 브라우저 메인 프로세스(AppKit/CrBrowserMain)에 HTTP 캐시 메타데이터가 쌓여 가상 메모리(va_size)가 고갈되는 현상 원천 차단
4. **JSON 수동 메모리 해제 (`GC Trigger`)**: 조회 후 즉시 대형 JSON 참조를 끊어 V8 가비지 컬렉터가 즉시 수거하도록 유도
5. **코레일 10분 자동 로그아웃 킬러 무력화 (`keepAlive`)**: 가상 사용자 인터랙션 디스패치로 장시간 무중단 감시 유지
6. **4초 타임아웃 안전망 (`AbortController`)**: 통신 지연 시 무한 대기로 브라우저 소켓이 잠기는 현상 방지
